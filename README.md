## About this site

Accessible, responsive static HTML, CSS, and JavaScript. No build step, tracking, external fonts, or dependencies. Serve the repository with any static web server. GitHub Pages publishes the `main` branch from the root folder.

Project photos come from my supplied engineering portfolio. CAD previews come from the exoskeleton and bionic arm project materials; the hand GIF is an illustrative CAD pose sequence.
